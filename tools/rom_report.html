Function field guide

Named code entries, static call targets, and observed runtime entries. Task labels are inferred from symbols, source comments, and the documented audio range.

How to read this report. Source instructions are checked against the supplied ROM. Raw binary inclusions stay unknown unless execution or source evidence identifies them. “Data read” describes observed access, not a proven data type. Unexecuted source code is still code. Orange highlights static and recorded call / restart instructions, plus recorded computed jumps; interrupt events have no calling instruction to mark. Function bodies follow direct control flow and stop at other entries, returns, and unresolved computed jumps; shared tails can belong to several functions. Cross-bank static call targets are provisional because the active bank may change at runtime; recorded callers retain actual bank addresses. Counts describe only the supplied recorded runs, not all possible playthroughs. Expanded functions contain all recovered body instructions and their source comments.
